Misi Terakhir: Manajemen Kategori

Klien senang dengan fitur Produk yang Anda buat. Sekarang, mereka meminta fitur tambahan untuk mengelola Kategori Barang (Elektronik, Pakaian, Makanan, dll).

Tantangan: Kerjakan fitur ini dengan melihat kode Produk sesedikit mungkin!

TARGET HASIL

Target Tampilan

Fokuslah membuat fungsionalitas CRUD agar tampilan akhirnya terlihat seperti ini. Tidak perlu persis 100%, yang penting struktur datanya benar.

Spesifikasi Teknis

  • 1. Database: Buat tabel kategori (id, nama, deskripsi).
  • 2. CRUD: Admin bisa Tambah, Lihat, Edit, dan Hapus kategori.
  • 3. Validasi: Nama kategori wajib diisi.
  • 4. Sidebar: Tambahkan menu "Kategori" di sidebar layout admin.

Peta Pengerjaan

Langkah 1: Database

Make Model & Migration (-m). Isi kolom table.

Langkah 2: Controller & Route

Buat KategoriController. Copy logic Produk, sesuaikan nama variabelnya.

Langkah 3: View (Tampilan)

Buat folder views/kategori. Buat file index, create, edit.

Langkah 4: Finishing

Pasang menu di Sidebar. Test fitur tambah, edit, hapus.

Butuh Bantuan? (Cheat Sheet)

Terminal Commands

$ php artisan make:model Kategori -m

$ php artisan make:controller KategoriController

$ php artisan migrate

Pola Route (web.php)

// Daftar Kategori

Route::get('/kategori', [KategoriController::class, 'index']);

// Tambah

Route::get('/kategori/create', [KategoriController::class, 'create']);

Route::post('/kategori', [KategoriController::class, 'store']);
