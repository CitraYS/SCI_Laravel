Sesi 15: Admin Dashboard & Data Table

UI Structure

1. Konsep: Struktur Halaman Admin

Admin butuh tampilan data yang Padat & Informatif. Bukan kartu cantik, tapi TABEL.

Kita akan mengubah tampilan index.blade.php yang tadinya Grid/Card menjadi Tabel Baris (Row) dengan kolom aksi lengkap.

2. Persiapan Data (Backend)

Sebelum membuat tampilan, pastikan data sudah dikirim dari Controller.

A. Controller (ProdukController.php)

public function index()
{
    // Ambil data produk terbaru
    $produk = \App\Models\Produk::latest()->get();

    // Kirim ke view 'produk.index'
    return view('produk.index', compact('produk'));
}

B. Route (web.php)

use App\Http\Controllers\ProdukController;

Route::get('/produk', [ProdukController::class, 'index']);

4. Membuat Data Table (View)

Edit file resources/views/produk/index.blade.php. Kita ganti tampilan kartu menjadi tabel.

@extends('layouts.admin')

@section('content')
    
    <!-- Header Halaman -->
    <div class="flex justify-between items-center mb-6">
        <h2 class="text-2xl font-bold text-slate-800">Daftar Produk</h2>
        
        <!-- Tombol Tambah -->
        <a href="/produk/create" class="bg-blue-600 text-white px-4 py-2 rounded shadow hover:bg-blue-700 transition">
            + Tambah Produk
        </a>
    </div>

    <!-- Tabel Data -->
    <div class="bg-white rounded-lg shadow overflow-hidden">
        <table class="min-w-full">
            <thead class="bg-slate-50 border-b">
                <tr>
                    <th class="px-6 py-3 text-left text-sm font-bold text-slate-500 uppercase">Nama Produk</th>
                    <th class="px-6 py-3 text-left text-sm font-bold text-slate-500 uppercase">Harga</th>
                    <th class="px-6 py-3 text-left text-sm font-bold text-slate-500 uppercase">Stok</th>
                    <th class="px-6 py-3 text-center text-sm font-bold text-slate-500 uppercase">Aksi</th>
                </tr>
            </thead>
            <tbody class="divide-y divide-gray-200">
                @forelse($produk as $item)
                    <tr class="hover:bg-slate-50 transition">
                        <td class="px-6 py-4 text-slate-700">{{ $item->name }}</td>
                        <td class="px-6 py-4 text-slate-700">Rp {{ number_format($item->price) }}</td>
                        <td class="px-6 py-4">
                            @if($item->stock < 5)
                                <span class="bg-red-100 text-red-700 text-xs px-2 py-1 rounded font-bold">{{ $item->stock }} (Menipis)</span>
                            @else
                                <span class="bg-green-100 text-green-700 text-xs px-2 py-1 rounded font-bold">{{ $item->stock }}</span>
                            @endif
                        </td>
                        
                        <!-- Kolom Aksi -->
                        <td class="px-6 py-4 text-center space-x-2">
                            
                            <!-- Tombol Edit -->
                            <a href="/produk/{{ $item->id }}/edit" 
                               class="text-yellow-600 border border-yellow-300 px-3 py-1 rounded hover:bg-yellow-50 text-sm transition">
                                Edit
                            </a>

                            <!-- Tombol Hapus (Wajib pakai Form agar aman) -->
                            <form action="/produk/{{ $item->id }}" method="POST" class="inline" 
                                  onsubmit="return confirm('Yakin ingin menghapus data ini?')">
                                @csrf
                                @method('DELETE')
                                <button class="text-red-600 border border-red-300 px-3 py-1 rounded hover:bg-red-50 text-sm transition">
                                    Hapus
                                </button>
                            </form>
                        </td>
                    </tr>
                @empty
                    <tr>
                        <td colspan="4" class="text-center p-6 text-gray-500">
                            Belum ada data produk. Silakan tambah data baru.
                        </td>
                    </tr>
                @endforelse
            </tbody>
        </table>
    </div>

@endsection
